# GSM827073 데이터셋 설명

## 1. 개요

| 항목 | 내용 |
|------|------|
| GEO Accession | [GSM827073](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM827073) |
| 데이터 유형 | 유전자 발현 (Gene Expression) 마이크로어레이 |
| 플랫폼 | Agilent 1-color microarray |
| 원본 파일 | `GSM827073_US10283824_252800412039_S01_GE1_107_Sep09_1_2.txt.gz` |
| 제공 기관 | NCBI GEO (Gene Expression Omnibus) |

본 데이터는 Agilent Feature Extraction 소프트웨어로 생성된 **단일 샘플(단일 채널, Cy3)** 유전자 발현 측정 결과이다.  
실습에서는 압축 파일(`.txt.gz`)을 해제한 뒤 FEATURES 영역을 전처리하여 머신러닝용 CSV로 변환한다.

---

## 2. 생물·실험 맥락

동일 스캐너·프로토콜 계열의 GEO 샘플(예: GSM827081)과 파일 명명 패턴을 보면, 본 샘플은 **사람(Homo sapiens) 유방암 관련 유전자 발현 연구 시리즈**(GSE33447 / GSE33450 계열)에 속할 가능성이 높다.

- **측정 분자**: total RNA → aRNA/cDNA → Cy3 라벨링
- **하이브리드화**: Agilent Gene Expression Hybridization 프로토콜
- **스캔**: Agilent G2505C Scanner (`US10283824`)
- **프로토콜**: `GE1_107_Sep09` (1-color, Feature Extraction)

> 샘플의 정확한 조직 유형·환자 정보는 GEO 페이지의 Sample characteristics를 확인한다.

## 3. 원본 파일 구조

Agilent Feature Extraction TXT는 여러 섹션이 한 파일에 이어져 있다.

| 섹션 | 역할 |
|------|------|
| `FEPARAMS` | 스캔·그리드·프로토콜 메타데이터 |
| `STATS` | 전체 칩 통계(배경, QC 등) |
| `FEATURES` | **probe별 측정값** (분석의 핵심) |

### 3.1 칩(그리드) 정보 (FEPARAMS 요약)

| 항목 | 값 |
|------|-----|
| Protocol | GE1_107_Sep09 |
| Scanner | Agilent G2505C US10283824 |
| 채널 수 | 1 (단일 채널) |
| Scan Date | 2011-04-19 |
| Grid Name | 028004_D_F_20110325 |
| Grid 크기 | 384 rows × 164 cols |
| Feature(스팟) 수 | 62,976 (= 384 × 164) |

`028004` 그리드는 Agilent SurePrint G3 Human Gene Expression 8×60K 계열 어레이 디자인에 해당한다.

### 3.2 FEATURES 주요 컬럼

| 컬럼 | 설명 |
|------|------|
| `FeatureNum` | Feature(스팟) 번호 |
| `Row`, `Col` | 칩 상의 위치 |
| `ControlType` | 0=biological, ≠0=control probe |
| `ProbeName` | Agilent probe ID (예: `A_23_P326296`) |
| `SystematicName` | 유전자/전사체 ID (예: `NM_144987`, `ENST...`) |
| `gProcessedSignal` | 배경 보정·처리된 발현 신호 (분석용) |
| `gMedianSignal` | 중앙값 원시 신호 |
| `gBGMedianSignal` | 배경 중앙값 |
| `gIsPosAndSignif` | 1이면 양수·유의한 신호 |
| `gIsWellAboveBG` | 1이면 배경보다 충분히 높음 |
| `gIsSaturated` | 포화 여부 |
| `gIsFeatNonUnifOL` 등 | QC outlier 플래그 |

## 7. 활용 시 참고

1. **단일 샘플**이므로 샘플 간 비교·차등발현(DEG)에는 동일 시리즈의 다른 GSM이 추가로 필요하다.
2. `SystematicName`에는 RefSeq(`NM_`), Ensembl(`ENST`), lincRNA 좌표 등 **이질적인 ID**가 섞여 있을 수 있다. 유전자 단위 집계 시 매핑이 필요할 수 있다.
3. 최종 CSV의 `gProcessedSignal`은 이미 **log2 스케일**이다. 다시 log를 취하지 않도록 주의한다.
4. 저발현 필터(하위 25%)는 실습용 기준이며, 연구 목적에 따라 임계값을 조정할 수 있다.
